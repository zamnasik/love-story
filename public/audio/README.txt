PUT YOUR MUSIC HERE
===================

Save a legally usable instrumental track as:

    public/audio/romantic-piano.mp3

The website looks for exactly that file name. If the file is missing, the site
automatically plays a soft built-in ambient piano-and-pad melody instead (generated in
the browser, so there is nothing to license), and everything still works.

Good, legal sources of calm piano music:
  - Pixabay Music (pixabay.com/music)       - Pixabay Content License
  - Free Music Archive (freemusicarchive.org) - check each track's licence (CC0 / CC BY)
  - Incompetech (incompetech.com)            - CC BY 4.0 (needs a credit line)
  - Or a track you composed / commissioned / licensed yourself.

Always read the licence of the exact track. If it needs attribution (CC BY), add a
small credit in the closing scene (src/components/ClosingScreen.tsx).
Aim for a seamless loop, 2-4 minutes, under ~5 MB (128 kbps mp3) so it loads fast on mobile.
